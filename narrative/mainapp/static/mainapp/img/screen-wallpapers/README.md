# Screen wallpaper pack

Three original images generated for NarrativeAI using OpenAI's image-generation
tool on 2026-11-20, then exported to WebP at quality 84. No community preset or
third-party illustration was used as a reference. Originals remain in the working
environment's generated_images directory; these are the application-ready exports.

- `moonlit-library.webp`: moonlit observatory/library above a violet sea.
- `cloud-station.webp`: a quiet railway station and warm carriage above twilight clouds.
- `night-greenhouse.webp`: a floating greenhouse with muted foliage and a glowing teapot.

The compositions reserve dark, quiet space on the left for launcher text. The
Screen stylesheet adds a contrast overlay and adjusts the crop on small screens.
These are static bundled assets: opening or selecting one makes no model request.
The existing four gradient palettes remain available.

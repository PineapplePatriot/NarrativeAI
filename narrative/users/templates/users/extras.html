Extras

The optional bits around the chat. Change them any time; nothing here is required.

🔊 Voices

Characters can read their replies aloud through ElevenLabs (a separate account and key). You then pick a voice for each character in its Advanced settings.

📚 Story summary

Long chats get summarized so the AI remembers older events without rereading everything.

📊 Story trackers

Keeps track of where you are, who's around, relationships, inventory and so on. Which trackers each character uses is picked on that character's Trackers page (from the chat's menu); none are on until you choose.

🎭 Character sprites

If a character has pictures for different emotions, the chat shows the one that matches each reply. That takes one small extra call per reply. Pictures can be made with Nano Banana in Gemini.

💸 Background jobs

Summaries, trackers and sprites run alongside your chat with . A cheaper model does them just as well and can save a lot on expensive chat models. It uses the same OpenRouter key.
